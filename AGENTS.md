## Development

When starting the dev server, use background mode:

```
astro dev --background
```

Manage the background server with `astro dev stop`, `astro dev status`, and `astro dev logs`.

## Verification

Whatever action you can do yourself, please do yourself. This includes starting apps and performing verification.

## Project Context

`mozartmusicstore` is an Astro storefront project managed with pnpm.

Mozart is a music store based in Alajuela, Costa Rica. It connects musicians with affordable instruments and accessories, so they can browse products from home. Its catalog includes guitars, basses, pianos, ukuleles, strings for any instrument, gig bags, mixers, speakers, cables, drums and drum kits, violins, violas, and cellos.

The current scope is the landing page only. It must showcase three products, each with a button that opens WhatsApp so customers can contact the store to buy that item. Do not add other pages until the landing page has been polished and approved.
